# 02-09-2026 — Learning

## The headline

**A Bull Put Spread was recommended against a Slightly Bearish view.** It was caught by the user, not by the gates. No trade was taken, so the cost was zero — but the same failure cost **−₹15,564 on 01-Sep-2026**, one session earlier. Two occurrences in two sessions makes it a process defect, not a slip.

---

## Root cause 1 — the ceiling rule inspected the wrong participant

`find-trade.md` computed only `Pro_net_CE_short`. 01-Sep participant data (T-1 for today):

| | Idx Fut | Idx CE net | Idx PE net | Posture |
|---|---|---|---|---|
| **FII** | −12,717 | **−93,282** | **−69,518** | Short futures + short strangle |
| **Pro** | +3,617 | **+168,089** | **+131,998** | Long straddle ~300K |

- **FII was net short 93,282 calls — above the 80,000 hard-ceiling threshold.** The rule never looked at FII, so it never fired.
- Pro was net *long* 168,089 calls → `Pro_net_CE_short = −168,089` → scored `< 50,000` → "normal".
- **A `< 50,000` score was then read as an endorsement of PE-first.** It is not. The rule's own text says *"apply the §8.5 grid and §8.5.4 as usual"* — it hands the decision to the grid. Silence is not a vote.

CLAUDE.md already states **"FII = primary trend setter"**. The rule contradicted the doc it lived under.

## Root cause 2 — the wrong cell of the §8.5 grid was read

VIX 11.70 → **CHEAP**. `CHEAP × Slightly Bearish → Bear Call Spread`. `NORMAL × Slightly Bearish → Bull Put Spread`. Different cells. The NORMAL row was applied at CHEAP vol.

## Root cause 3 — morning spread P&L was used as a directional signal

The argument was: *"bull put decayed 19 pts, bear call widened 8.6 pts → sell puts."* Both halves are wrong:

- For a **credit seller a widened spread is a BETTER entry**, not a broken structure. SENSEX 77,000 CE was 68.85 at 09:30 and 91.00 at 10:30 — 32% more premium for the same strike.
- The bull put's "decay" was **delta from a 340-pt bounce, not theta.** That exact point had already been made about NIFTY in the same analysis and was not carried across.

## Root cause 4 — Pro's 300K long straddle was rationalised away

Recorded in the market view, then dismissed with *"the move arrived before 9:16, so a paid straddle gets monetised → vol-negative from here."* That is a rationalisation. **A long-gamma book re-hedges and stays long gamma; it does not become a premium seller because one leg paid.** Selling premium to the largest long-gamma buyer on the board deserved a size cut, not an inverted sign.

## Root cause 5 — the stop's spot level was estimated by eye

Quoted as SENSEX ≈76,870 at 10:44. Derived properly from the chain's own strike-to-strike price differences — Δ(76,800)≈0.26, Δ(77,000)≈0.175, spread delta ≈0.085 — the true level was **~76,650**, i.e. *inside* the day's demonstrated 397-pt range rather than 200 pts beyond it. A materially different risk picture, quoted with unwarranted confidence.

## Non-process lessons worth keeping

- **A pre-market field with no data in it must read "unknown", never a value with a green tick.** The 07:36 basis table recorded `~0 ✅ Low basis` while explicitly noting option LTPs were zero. Measured live: +61 / +88 / +357 — all above threshold.
- **Dhan MCP OAuth is unreliable — go to REST after one attempt.** Failed twice today (07:17, 09:27). `complete_login` replying `token_id already consumed` is **not** proof of binding; only a successful `expirylist` is. REST (`access-token` + `client-id`) carried the whole session.
- **Kite and Kotak sessions both dropped between 07:17 and 09:16.** A 07:00 login does not survive to the open. Re-verify at 09:10.
- **NIFTY at 4 DTE has no intraday theta, and it is measurable rather than assumable.** The 100-wide condor went 66.00 → 65.10 → 65.25 → 64.90 across the morning: **1.1 pts in 75 minutes.** Also, when credit > width/2 the k=1.5 stop sits beyond max loss — the structure has no working premium stop at all.
- **Data older than ~45 minutes must be re-pulled before a trade call.** The 09:30 snapshot said kill switch 1/3; the 10:25 re-pull said 0/3, with NIFTY 23,800 PE OI up 4.1M. Opposite conclusions.
